## Overview

The site is designed to present:

- a professional introduction and personal brand
- technical skills across development, systems, and security
- selected project highlights
- a decision-making and AI usage narrative
- education and career readiness summary
- contact information for networking or inquiries

## Project type

- Static website
- HTML + CSS + JavaScript
- Bootstrap-based layout and icons
- Responsive design for desktop and mobile viewing

## Main file

- `index.html` — contains the full page structure, styling, content, and interactive logic

## How to view locally

Open `index.html` directly in a browser, or run a small local server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```
